01

THREAT INVESTIGATION

Phishing Email Investigation & IOC Analysis

Why I built it

I wanted to understand how a SOC analyst would investigate a suspicious email reported by an employee and determine whether it was malicious.

Objective

Analyse a simulated phishing email, identify indicators of compromise and document the investigation.

What I used

  • Email header analysis
  • VirusTotal
  • CyberChef
  • URL/domain analysis

What I did

  • Analysed the email headers
  • Checked the sender and sending infrastructure
  • Extracted URLs and other indicators
  • Analysed suspicious links
  • Checked indicators against threat intelligence sources
  • Documented the evidence
  • Reached a final verdict on whether the email was malicious

What I learned

  • How to analyse suspicious emails
  • How to identify and extract IOCs
  • How to use threat intelligence during an investigation
  • How to document security findings clearly
Outcome: Created a structured phishing investigation report containing the evidence, analysis and final verdict.
Evidence: Investigation report Screenshots of the analysis Sample email headers IOC list
02

HOME SOC / THREAT DETECTION LAB

Building a Mini SOC Lab for Threat Detection

Why I built it

I wanted to understand how security analysts collect logs, investigate suspicious activity and create detections in a realistic environment.

Objective

Build a small home lab where I could generate security events, collect logs and investigate suspicious activity.

What I used

  • Windows virtual machine
  • Sysmon
  • Splunk
  • Windows Event Log
  • PowerShell

What I did

  • Set up a Windows virtual machine
  • Investigated suspicious PowerShell activity
  • Created a basic detection query
  • Documented the investigation process

What I learned

  • Windows security logging
  • SIEM fundamentals
  • Log analysis
  • Detection engineering
  • Basic threat investigation
Outcome: Built a working home SOC environment and created a basic detection for suspicious PowerShell activity.
